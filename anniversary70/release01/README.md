# ホンヤク出版社 創業70周年記念動画｜第1稿

7分00秒、フルHD（1920×1080）、30fps。字幕とBGMで構成し、ナレーションは入れていません。
役員3名と社員集合写真はユーザー提供のラフPowerPointに含まれる実写真を使用しています。役員写真は代表を中央のまま配置しました。

## ファイル

- anniversary70.mp4：完成動画。BGM入り。
- anniversary70.pptx：全28枚、各15秒の編集可能なPowerPoint。写真は画像、字幕と図解は編集可能です。
- soundtrack.mp3：全7分の音楽。PowerPointには埋め込んでいません。
- captions.csv：各シーンの開始・終了時刻と字幕。
- sources.md：参考資料と素材の整理。

## PowerPointからMP4を書き出す

1. 1枚目を選び、「挿入」→「オーディオ」から同梱のsoundtrack.mp3を追加します。
2. 音声を選び、「再生」→「バックグラウンドで再生」を設定します。「停止するまで繰り返す」はオフにします。
3. 「ファイル」→「エクスポート」→「ビデオの作成」でフルHDを選びます。
4. 「記録されたタイミングとナレーションを使用する」を選択します。各スライドは15秒に設定済みです。
5. MPEG-4形式で保存します。PowerPointの切り替え処理により、お渡ししたMP4とタイミングや動きが多少異なる場合があります。
