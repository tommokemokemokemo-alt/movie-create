# 創業70周年記念動画｜動きと音楽を見直した第2稿

全長7分00秒。112カット。3秒または4秒ごとの編集を基本に、写真の移動、重なり、寄り引き、コピーカード、図解の線の展開を組み合わせています。
動画はフルHD（1920×1080）、24fps、ステレオBGM付き。ナレーションは入れていません。

## ファイル

- anniversary70-motion.mp4：動き・音楽を組み込んだ完成動画。
- preview-60s.mp4：過去・現在・未来から20秒ずつ抜粋した60秒の確認版（本編00:00–00:20、03:30–03:50、06:15–06:35）。
- anniversary70-motion.pptx：112枚の編集用PowerPoint。字幕は編集可能です。
- soundtrack.mp3：全7分のBGM。PowerPointには未埋め込みです。
- captions.csv：各カットの開始・終了時刻と字幕。
- sources.md：素材と音楽の説明。

## PowerPointについて

PowerPointの背景は、動画の各カットから作った代表フレームです。字幕はテキストボックスとして編集できます。
動画の写真が独立して移動・重なり合う演出やカメラの動きはMP4で確認してください。PowerPointから再書き出ししても、その動きまで同一にはなりません。
各スライドは4秒・4秒・4秒・3秒の順で、全体7分のタイミングを設定しています。

音声を入れるには、1枚目で「挿入」→「オーディオ」からsoundtrack.mp3を選び、「バックグラウンドで再生」を設定します。「停止するまで繰り返す」はオフにします。
MP4書き出しでは「記録されたタイミングとナレーションを使用する」を選択してください。PowerPoint独自の切り替え処理により、動画と全体尺が多少異なる場合があります。
