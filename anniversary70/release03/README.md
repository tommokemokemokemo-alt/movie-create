# 創業70周年記念動画｜祝福・新ビジュアル・立体CG版

70周年記念イベントの冒頭で上映する、明るく祝福感のある7分版です。

- 新しく生成した画像26点を、それぞれ一つのシーンだけに使用。
- Blenderで立体モデルを制作したCGアニメーション28シーン。
- 役員3名と社員集合の実写真を、それぞれ一つのシーンに使用。
- 全56シーン、各7.5秒、全長7分00秒。
- 字幕は画面中央下の大きな1〜2行に集約。離れた見出しを読む必要はありません。
- BGMは全編を明るい長調で構成し、過去・現在・未来で編成やテンポを変えています。

## ファイル

- anniversary70-celebration.mp4：本編。フルHD、24fps、H.264 4:2:0、AACステレオ。
- preview-60s.mp4：映像と音楽を確認する60秒のダイジェスト。本編の抜粋をつないだものです。
- anniversary70-celebration.pptx：56枚の編集用PowerPoint。字幕は48ポイント。CG場面は動画を埋め込んでいます。
- soundtrack.mp3：全7分のBGM。PowerPointには別途追加してください。
- captions.csv：各シーンの時刻と字幕。

## PowerPoint

CG場面はMP4を埋め込み、自動再生を設定しています。写真場面のパン・ズームは本編MP4に含まれます。PowerPointの写真背景は代表フレームです。

1枚目で「挿入」→「オーディオ」からsoundtrack.mp3を追加し、「バックグラウンドで再生」を選択します。「停止するまで繰り返す」はオフにしてください。
動画を書き出す場合は、「記録されたタイミングとナレーションを使用する」を選びます。各スライドの切り替えは7.5秒です。
PowerPoint独自のメディア再生や切り替え処理により、お渡しした本編MP4とタイミングや写真の動きが完全には一致しない場合があります。

## CGについて

実写調のAI動画を直接生成するツールは、この制作環境にはありません。
CGはBlenderによる立体アニメーションです。飛行・航行・走行・建機のアーム・部品の分解組み立て・ロボット・情報のつながりなど、モデル自体を動かしています。実在する特定機種の精密モデルではなく、技術分野を伝える模式的なCGです。
